# Sprocket (pf_rookie) rig — v001

Original Piggy Firefighters art only (registered r2 parts under `art-src/animation/parts/pf_rookie`,
provenance in the parts `registration.json`). No paid generation, no repainting: every draft
texture is a byte-identical copy of a delivered PNG and `source-record.json` carries the hashes.
Contract: `docs/ANIMATION_CONTRACT.md` (380 px, root at the feet, clips `idle · fumble · card_flip ·
hold_sheet · catch · celebrate · sad`, events `flip`/`catch`, anchors `sheet_l`/`sheet_r`).
Acting brief: `art-src/animation/rigs/DIRECTION.md`.

## Files

| File | Role |
| --- | --- |
| `author_rookie.py` | Chief-pattern authoring script: measures the layout from the parts, builds bones/slots/attachments, writes `pf_rookie.json` + frozen `images/` into a NEW draft. `--preview-only` writes just `setup-preview.png` and the layout. |
| `rookie_performances.py` | The seven clips (keyed in 380 px units; sign conventions in its docstring). |
| `rookie-layout.json` | Layout of record: the measurements `author_rookie.py` made against registration sha256 5ce067c99c39… (fits, cuff centres, hand axes, anchors). Regenerated by the script; kept for review. |
| `rookie.export.json` | Pinned 4.2.43 export preset (copy of `pf_chief/pilot.export.json`: JSON + attachment-packed atlas, straight alpha, 1x, pages ≤ 2048, strip whitespace, bleed). |
| `finish_export.mjs` | Derives the CLI-omitted `skeleton.x/y/width/height` with the installed spine-core 4.2.74 through `AtlasAttachmentLoader` over the real exported atlas; writes a separate `runtime/` copy, never edits the native export. |
| `drafts/v001/` | Authored JSON, frozen images, `pf_rookie.spine` (authoritative native project, CLI import), `export/pf_rookie/` (native 4.2.43 export), `runtime/` (bounds-completed runtime copy), `setup-preview.png`, records. |

## Build (fresh draft each time)

```sh
python3 -B art-src/animation/rigs/pf_rookie/author_rookie.py --output art-src/animation/rigs/pf_rookie/drafts/vNNN
mkdir art-src/animation/rigs/.spine.lock   # shared CLI lock: retry every 5 s while it exists, ≤ 15 min
PF_SPINE=/Applications/Spine.app/Contents/MacOS/Spine; D=$PWD/art-src/animation/rigs/pf_rookie/drafts/vNNN
"$PF_SPINE" --update 4.2.43 --disable-audio -i "$D/pf_rookie.json" -o "$D/pf_rookie.spine" -r
"$PF_SPINE" --update 4.2.43 --disable-audio -i "$D/pf_rookie.spine" -o "$D/export/pf_rookie" -e "$PWD/art-src/animation/rigs/pf_rookie/rookie.export.json"
rmdir art-src/animation/rigs/.spine.lock
node art-src/animation/rigs/pf_rookie/finish_export.mjs "$D/export/pf_rookie" "$D/runtime"
cp "$D"/runtime/pf_rookie.{json,atlas,png} apps/piggy_firefighters/static/assets/spine/pf_rookie/
python3 art-src/animation/tools/check_contract.py --rig pf_rookie
```

Never open the project in Spine 4.3; never import over an edited `.spine`.

## Rig

- Root `(512,1440)` canvas = feet; standing scale `380 / 1440` (master alpha box, soles on y 1440; the one faint crown row at y 0 is accepted per the parts delivery note).
- Bones: `body` (hips) → `chest` → `head` → `helmet`, `ear_r`/`ear_l`, `brows`, `eyes`, `mouth`; `coat` (belt pivot); `leg_r`/`leg_l` pivot at the soles so knees splay without lifting the boots; arm chains `arm_* → fore_* → hand_*` (shoulder pivots from the registered raised-arm split, wrist = navy cuff centroid, elbow mid-axis); anchors `sheet_r`/`sheet_l` are children of the wrists at the measured catch-hand fingertip (`anchors.json`); `card` (world-upright child of `hand_r` at the pinch tip); `hose` (belly, child of body) → `hose_tail`.
- Attachments: full-canvas layers as regions (`leg_left`, `leg_right`, `coat_tails`, `head_blank`, `helmet_front`); the torso and both sleeves are weighted UV strip meshes on `body_no_head_no_arms` / `arm_left` / `arm_right` (the sleeve strip ends at the cuff, so the painted hand is excluded and the delivered hand variants `open/grip/pinch/catch` sit on the wrist with their cuff axis aligned to the forearm); face pieces at their registered family scales (eyes 0.6, brows 0.5, mouth 0.32, ears 0.45), variants aligned to the neutral piece (brows by base, mouths by upper lip, closed/happy eyes on the lower lid); props `hose_coil`, `hose_flexible` (0.316), `card_back`/`card_blank` (0.6) hidden in setup and keyed only inside `fumble` / `card_flip`.
- Draw order (back → front): hose tail, far leg, near leg, coat, torso, head, helmet, far ear, near ear, brows, eyes, mouth, hose coil, far sleeve, far hand, near sleeve, near hand, card.
- Unused in v001 (available for a later pass): `arm_*_raised`, `hand_*_point`, `helmet_only`, `head_no_helmet`, `legs.png`, `arms_*.png` combined layers.

## Clips (all roots unkeyed; ≥ 8 moving bones each)

`idle` 4 s loop (chest breath, lagging helmet/ears, two unequal blinks) · `fumble` 2.5 s (anticipation → coil slips → eye dart / embarrassed brows / oops → scoop, regrip, relief) · `card_flip` 1 s (pinch hand leads, forearm presents at chest, wrist flick with the card edge-on at .45 s = `flip`, blank face revealed, grip settles) · `hold_sheet` 3 s loop (arms out, catch hands, looking up, breath through the arms) · `catch` .7 s (`catch` at .05 s; body drops 13 px, elbows/knees give, rebound, settles into the exact hold pose so it mixes back cleanly) · `celebrate` 1.5 s (crouch, both arms up, two pumps, settle) · `sad` 1.5 s (droop, slow blink, restrained recovery).
